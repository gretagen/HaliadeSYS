# About this distribution
HaliadeSYS (AKA : Haliade OS) is a strictly universal imperative-declarative hybrid Linux distribution that is designed to be reproducible, fast to deploy, easy to learn, and performant.
It is worked on by a single developer, along with some contributors.

Some features of HaliadeSYS include :

-- Subspaces (allows you to use other distros in isolated environments, along with merging their packages to the actual system)

-- Hybrid usage (allows you to either declaratively configure the whole system or use it normally like any other imperative distro)

-- Reproducibility (With easy home management so you can reproduce your own dotfiles and a system config so you can reproduce your system on any Haliade machine)

-- Generations (allows you to rollback if your system breaks)
